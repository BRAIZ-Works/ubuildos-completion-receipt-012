# Start Here

Day 11: Prospect Qualification Pipeline

Purpose: make prospect qualification inspectable by showing the exact fit, need, timing, and next-step evidence used for each outcome.

Use the final build to:
1. review the pipeline;
2. open a prospect criteria card;
3. inspect the evidence and reason;
4. filter `QUALIFIED`, `DISQUALIFIED`, or `REVIEW`;
5. export the current view.

Any missing or contradictory required evidence routes to `REVIEW` instead of being guessed.
